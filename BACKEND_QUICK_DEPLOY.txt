USING YOUR API (FROM ANY FRONTEND):
================================================================================

Python Example:
--------
import requests

url = "https://shield-backend-xxxxx-us-central1.a.run.app/predict/single"
data = {
    "Amount": 150.0,
    "Time": 3600,
    "Distance_From_Home": 30.0,
    "selected_model": "xgboost"
}

response = requests.post(url, json=data)
result = response.json()

print(f"Fraud Probability: {result['fraud_probability']}")
print(f"Status: {result['status']}")

JavaScript Example:
--------
const url = "https://shield-backend-xxxxx-us-central1.a.run.app/predict/single";
const data = {
    Amount: 150.0,
    Time: 3600,
    Distance_From_Home: 30.0,
    selected_model: "xgboost"
};

const response = await fetch(url, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(data)
});

const result = await response.json();
console.log(result);

IF SOMETHING GOES WRONG:
================================================================================

Problem: "Deployment failed"
Fix: Make sure Dockerfile exists in your project root

Problem: "Models not found"
Fix: Check backend/ folder has both .pkl files

Problem: "Application error"
Fix: Go to Cloud Run console → Logs tab → read error

Problem: Still confused?
Fix: Read BACKEND_ONLY_DEPLOYMENT.md (detailed guide)
