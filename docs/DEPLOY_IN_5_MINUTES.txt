STEP-BY-STEP:
================================================================================

STEP 1: Open Google Cloud Console
--------
Go to: https://console.cloud.google.com

STEP 2: Open Cloud Shell
--------
Click >_ icon (top right corner)

STEP 3: Clone Your Repository
--------
git clone https://github.com/SaiMasram750/Credir_card_fraud.git
cd Credir_card_fraud

STEP 4: Deploy Backend
--------
gcloud run deploy shield-backend --source . --platform managed --region us-central1 --timeout 900

STEP 5: Answer Prompts
--------
Prompt 1: "Allow unauthenticated?" → Type: y → Press Enter
Prompt 2: "Which region?" → Just Press Enter

WAIT 5-10 MINUTES...
