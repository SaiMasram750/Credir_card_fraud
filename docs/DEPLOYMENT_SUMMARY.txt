Step 4: Deploy Backend
--------

Answer: y (for unauthenticated access)

✅ Save the URL you get!

Step 5: Update Frontend
--------
Edit: frontend/app.py (line 13)
Change API_URL from:
  API_URL = "http://127.0.0.1:8000"
To:
  API_URL = "https://shield-backend-YOUR-URL.a.run.app"

Save the file

--------

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Deployment fails
Solution: Check Dockerfile exists in root folder, make sure file paths correct

Problem: Frontend can't connect to backend
Solution: Check API_URL in frontend/app.py has https:// (not http://)

Problem: Models not loading
Solution: Check .pkl files exist in backend/ folder

Problem: Timeout error
Solution: Normal on first deployment, wait 10-15 minutes and try again

Problem: "Application error" in browser
Solution: Check Cloud Run Logs tab for specific error message
